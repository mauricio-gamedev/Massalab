# MassaFF Lab

Repositório do projeto MassaFF Lab — aplicativo Android experimental para investigar o visual de textura em blocos no Free Fire usando Shizuku e tecnologias ANGLE, sem root.

O repositório estava vazio. Este commit inicial apenas cria a branch padrão; o código-fonte será enviado em uma branch de trabalho separada para revisão por pull request.

Estado atual: protótipo experimental. Compatibilidade ANGLE, renderizador Vulkan e resultado visual ainda precisam ser validados em um Galaxy A06 SM-A065M com Android 16.
